# SATU

**Nota. Kira. Reka. Semua dalam SATU.**

Android-first, offline-first PWA prototype for Malaysian micro-sellers. V1 keeps business data on-device and avoids paid APIs.

## Stack
React + TypeScript + Vite. Local browser storage. Azure Static Web Apps target.

## Local development
```bash
npm install
npm run dev
npm run build
```

## V1 modules
Nota, Kira, Invoice, Resit, Reka, History, Settings, BM/English, JSON backup/restore and native sharing.

SATU V1 is not accounting or tax software and does not label documents as tax invoices.
